# cnbecom.github.io

Public GitHub Pages site for [Christopher Neil Becom](https://cnbecom.github.io/).

- Homepage: `index.md`, served by the Jekyll Minimal theme
- Application portfolio: `portfolio/b57e9817-dba2-4f96-977f-595098792068/`, standalone HTML copied from a private source repo

Do not edit the application portfolio HTML by hand. From the parent workspace root, update the private source and run `./generate public`, then commit this directory separately from any `index.md` homepage edits.

Local preview from the parent workspace root:

```
./generate preview
```
